## Expeditions — all projects

### 🌱 Verdant Leaf Health
A plant-photo screening prototype using Python, PyTorch, and MobileNetV3-Small, with a Flask scanner and a browser-side plant journal. It offers a broad healthy-or-diseased estimate to prompt a closer look; it is not a plant diagnosis. *(Private)*

### 🚦 Ridepulse
A Ridepulse-branded interface project built around Feast, the open-source feature store. *(Private; repository describes the UI as built on Feast.)*

### 🎨 Ganesha Code Art
A Python animation that reveals an image using colorful Devanagari characters, with the code and artwork shown together. *(Private)*

### 🏫 Civic Reporting System
A Flask app that gives campus reports a route from student submission to admin review and team assignment. *(Public)*

→ [Explore Civic Reporting System](https://github.com/AkshayaArveti/Civic-Reporting-System)
